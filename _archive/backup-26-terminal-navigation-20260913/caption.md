Navigasi terminal itu sederhana: tahu di mana (`pwd`), lihat ada apa (`ls`), lalu pindah tempat (`cd`).

Gunakan path relatif untuk jarak dekat (`cd project`) dan path absolut untuk lokasi pasti dari akar (`cd /home/adib/project`).

Simpan panduan ini agar kamu tidak pernah tersesat di terminal Linux!
