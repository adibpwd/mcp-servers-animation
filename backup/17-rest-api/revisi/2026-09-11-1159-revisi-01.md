## 1. Kondisi Sekarang

Intro `rest-api` (`Animation.jsx`, blok render header di IIFE dekat
baris ~510-545) sudah pakai mekanisme hacker-typing → header morph yang
sama seperti `tailscale`/`linux-vs-unix` (state `typed`, `cursorVisible`,
`morphP`, helper `typeLine` + `seededRandom01`). Yang belum sesuai cuma
warnanya — semua flat ungu (`COLORS.TECHNICAL` = `#A78BFA`):

- Tagline `NETWORKING · REST` → aksen `REST` pakai `COLORS.TECHNICAL`
- Title `REST API` → fill `COLORS.TEXT` (putih), TANPA split warna
- Cursor blok (`█`) di title maupun subtitle → `COLORS.TECHNICAL`
- Grid garis latar belakang (dekorasi, di luar blok header) juga pakai
  `COLORS.TECHNICAL` — lihat bagian 4 soal scope ini


## 2. Target

Ganti kombinasi warna intro (title + tagline + cursor) dari flat ungu
jadi kombinasi **hijau + biru**, sesuai contoh yang sudah dieksekusi di
`tailscale` (lihat referensi di atas). Pemetaan warna pakai palet yang
SUDAH ada di `data.js` topic ini sendiri (`COLORS`), tidak menambah
warna baru:

- **Hijau** → `COLORS.SUCCESS` (`#34D399`) — sudah dipakai di topic ini
  untuk "pola benar/sukses" (status 200/201 di Act 5)
- **Biru** → `COLORS.CLIENT` (`#38BDF8`, sky blue) — sudah dipakai untuk
  "client/pengirim" (Act 1-4)

Title `REST API` di-split 2 warna pakai multi-`tspan` (pola sama seperti
`tailscale` split `TAIL`/`SCALE`): draft awal `REST` hijau (`SUCCESS`),
`API` biru (`CLIENT`) — titik split ini PERLU dikonfirmasi/preview di
browser dulu, bukan tebakan final (lihat bagian 6).

- Tagline aksen `REST` → ganti dari `COLORS.TECHNICAL` jadi `COLORS.SUCCESS`
  (nyambung ke segmen awal title "REST" yang hijau)
- Subtitle tetap `COLORS.MUTED` (netral, tidak ikut ijo/biru) — biar
  kontras ke title tetap kebaca, sama seperti pola tailscale
- Cursor blok (`█`) ikut warna segmen yang lagi diketik: hijau selama
  posisi ketik masih di "REST", biru begitu masuk "API"; cursor di baris
  subtitle pakai biru (`CLIENT`) karena subtitle muncul setelah title
  penuh (sama pola seperti cursor akhir tailscale pakai `SUCCESS`)
- `filter="url(#glow)"` di title tetap dipertahankan, cuma source
  color-nya ganti (sudah otomatis ikut `fill` tiap `tspan`)

## 3. Kenapa Bukan Warna Lain (mis. `ADDRESS` cyan atau `TECHNICAL` ungu)

- `TECHNICAL` (ungu) sengaja ditinggalkan — itu justru warna yang mau
  diganti, dan warna ini masih dipakai luas di badge Act 3 (method) &
  Act 5 note, jadi tidak cocok dipertahankan juga di intro (bisa bikin
  intro dan badge method kelihatan sama padahal beda makna semantik).
- `ADDRESS` (cyan `#06B6D4`) sempat dipertimbangkan sebagai kandidat
  "biru" pengganti `CLIENT`, tapi `CLIENT` dipilih karena de facto jadi
  warna paling sering muncul mewakili "pengirim/aktor utama" sepanjang
  cerita (badge Act 1, envelope default), jadi lebih pas mewakili
  identitas intro. `ADDRESS` tetap dipertahankan khusus untuk elemen
  alamat/resource path di Act 3, tidak diusik plan ini.
- Tidak ada alasan "brand asli" yang perlu diikuti di sini (beda dari
  kasus tailscale yang brand aslinya merah/rust) — REST API bukan produk
  bermerek, jadi pemilihan warna murni ngikutin makna semantik internal
  project (`SUCCESS` = hijau, `CLIENT` = biru) biar konsisten sama Act
  lain di topic ini sendiri.

## 4. Scope — Cuma Intro, atau Grid Background Juga?

`COLORS.TECHNICAL` di file ini juga dipakai di elemen LAIN yang bukan
intro: grid garis latar belakang dekoratif (2 baris `<line>` sebelum
blok header, lihat kondisi sekarang §1), badge method di Act 3, dan
beberapa catatan Act 5. Plan ini **defaultnya HANYA ubah intro**
(title/tagline/cursor), TIDAK menyentuh grid background maupun elemen
`TECHNICAL` lain di luar intro — sama seperti keputusan default di plan
tailscale (bagian 8.3 referensinya). Kalau grid background ikut mau
diganti (misal ke `SUCCESS`/`CLIENT` juga biar 1 nuansa penuh dengan
intro), itu perlu dikonfirmasi eksplisit dulu (lihat bagian 6) karena
scope-nya lebih besar (grid tampil di SEMUA Act, bukan cuma saat intro).

```jsx

```

jadi (draft, titik split `titleSplitIdx = 4` = "REST" | " API" — lihat
catatan bagian 6 soal spasi):

```jsx
{(() => {
  const titleSplitIdx = 4 // "REST" (hijau) | " API" (biru) — perlu preview dulu
  const cursorColor = tt.length <= titleSplitIdx ? COLORS.SUCCESS : COLORS.CLIENT
  return (
    <>
      <text x={taglineX} y={taglineY} textAnchor="start" fill={COLORS.MUTED} fontSize={taglineFs} fontFamily="monospace" letterSpacing={2}>
        NETWORKING · <tspan fill={COLORS.SUCCESS} fontWeight={700}>REST</tspan>
      </text>
      <text x={titleX} y={titleY} textAnchor="start" fontSize={titleFs}
        fontFamily="'Arial Black', Impact, sans-serif" fontWeight={900} filter="url(#glow)">
        <tspan fill={COLORS.SUCCESS}>{tt.slice(0, titleSplitIdx)}</tspan>
        <tspan fill={COLORS.CLIENT}>{tt.slice(titleSplitIdx)}</tspan>
        {showIntro && tt.length < INTRO_TITLE.length && cursorVisible && (
          <tspan fill={cursorColor} fontWeight={900}>█</tspan>
        )}
      </text>
      <text x={subX} y={subY} textAnchor="start" fontSize={subFs} fontFamily="sans-serif" fill={COLORS.MUTED}>
        {typed.subtitle}
        {showIntro && tt.length === INTRO_TITLE.length &&
          typed.subtitle.length < INTRO_SUBTITLE.length && cursorVisible && (
          <tspan fill={COLORS.CLIENT} fontWeight={900}>█</tspan>
        )}
      </text>
    </>
  )
})()}
```

Mekanisme lerp posisi/ukuran (`titleX/Y/Fs`, `subX/Y/Fs`, `taglineX/Y/Fs`)
dan morph (`morphP`) **tidak berubah sama sekali**, sama seperti prinsip
