# Backup Redirect Standar Lama

Folder ini menyimpan sembilan file redirect lama yang sebelumnya berada di
folder standardizations utama. File-file ini bukan standar aktif dan tidak
boleh dipakai sebagai lokasi pembaruan aturan.

Gunakan [README standar aktif](../../docs/standardizations/README.md) untuk memilih salah satu dari
enam dokumen standar yang berlaku.
