Bekerja dengan file di terminal Linux tidak harus menakutkan — asal tahu tool dan caranya dengan aman. 👇

Membuat struktur folder dengan `mkdir -p`, menyiapkan file lewat `touch`, dan menyalin file dengan `cp` tanpa menghapus dokumen aslinya.

Memindahkan atau merename file memakai `mv`, dan menghapus file dengan opsi aman `rm -i` yang meminta konfirmasi sebelum benar-benar menghapus.

Membaca isi file sesuai kebutuhan: `cat` untuk file pendek, `less` untuk dokumen panjang, `head` untuk baris awal, dan `tail -f` untuk memantau log secara realtime.

Mencari lokasi file dengan `find` yang memindai folder atau `locate` yang membaca indeks sistem.

Menelusuri isi teks di dalam file menggunakan `grep`, abaikan kapitalisasi dengan `grep -i`, atau scan seluruh isi folder dengan `grep -r`.

Intinya: `find` untuk mencari nama file, `grep` untuk mencari isi teks di dalamnya. 📁
