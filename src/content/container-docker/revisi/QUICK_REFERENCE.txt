💻 QUICK DOWNLOAD SCRIPT:

```python
#!/usr/bin/env python3
import csv, os, requests
from pathlib import Path
from concurrent.futures import ThreadPoolExecutor

def download_icon(name, url, out_dir, cat):
    try:
        ext = '.svg' if 'svg' in url.lower() else '.png'
        fp = Path(out_dir) / cat / f"{name.lower().replace(' ', '-')}{ext}"
        fp.parent.mkdir(parents=True, exist_ok=True)
        r = requests.get(url, timeout=10, headers={'User-Agent': 'Mozilla/5.0'})
        r.raise_for_status()
        fp.write_bytes(r.content)
        print(f"✅ {name}")
        return True
    except Exception as e:
        print(f"❌ {name}: {e}")
        return False

# Read CSV and download
with open('icon-sources-mapping.csv') as f:
    tasks = [r for r in csv.DictReader(f) if r.get('Source URL')]

with ThreadPoolExecutor(max_workers=5) as ex:
    results = ex.map(
        lambda t: download_icon(t['Icon Name'], t['Source URL'], './icons', t['Category']),
        tasks
    )

print(f"\n✅ {sum(results)}/{len(tasks)} done")
```

Usage:
  pip install requests
  python download-icons.py

🔧 OPTIMIZATION COMMANDS:

# Validate SVG format:
  for f in icons/**/*.svg; do xmllint "$f" > /dev/null && echo "✅ $f" || echo "❌ $f"; done

# Minimize SVG files:
  npm install -g svgo
  svgo icons/**/*.svg --pretty

# Compress PNG files:
  brew install optipng  # or: apt-get install optipng

# Check image dimensions:
  identify icons/**/*.png | grep "256x256\|512x512"

🚨 COMMON ISSUES & FIXES:

Issue: "404 Not Found" on URL
  → Verify URL in browser first before scripting
  → Check Wayback Machine if site changed

Issue: "SVG has broken XML"
  → Run: svgo --input broken.svg --output fixed.svg
  → Or fallback to PNG version

Issue: "Download timeout"
  → Increase timeout in script (requests.get(..., timeout=30))
  → Try manual download for large files

Issue: "License unclear"
  → Email author/maintainer
  → Or find alternative source (Simple Icons has 3000+ as fallback)

Issue: "Icon doesn't match original"
  → Double-check you're using official source
  → Check Simple Icons CDN as alternative
  → May need to hand-edit or request official logo
