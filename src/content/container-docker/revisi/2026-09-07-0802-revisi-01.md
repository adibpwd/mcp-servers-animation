# Plan: Ganti Icon "Mirip Logo" (AI-generated) → Logo Asli dari Internet

**Masalah**: Banyak icon brand/logo di project ini di-generate lewat ChatGPT
image gen (`vm-icon-generator` extension). Untuk logo generik (gear, cloud,
dsb) itu oke, tapi untuk **logo brand/bahasa/OS yang orang sudah familiar
bentuknya**, hasil AI sering kurang akurat (proporsi salah, detail hilang).
Solusi: ambil file logo asli (SVG/PNG resmi) dari sumber terpercaya di
internet, lalu drop-in replace ke folder `icons/` masing-masing topic.

## 3. Kenapa Download-nya Lewat Terminal Desktop Commander, Bukan Sandbox Claude

Sandbox bash Claude (`bash_tool`) cuma boleh akses domain terbatas (npm,
pypi, github, crates.io, dst) — **`cdn.jsdelivr.net` dan
`commons.wikimedia.org` tidak termasuk**, jadi `curl` dari sana akan gagal.

Solusi: jalankan `curl`/`wget` lewat **`Desktop Commander:start_process`**,
yaitu terminal asli di komputer kamu (`/home/adb/...`) yang punya akses
internet penuh. Semua download & konversi file terjadi langsung di project
folder kamu, tidak lewat sandbox Claude sama sekali.

## 4. Cara Kerja Download (per icon)

1. Cari **slug** yang benar di Simple Icons/Devicon untuk tiap id
   (mis. `node-icon` → slug `nodedotjs`, `python-icon` → slug `python`,
   `redis-icon` → slug `redis`, `ubuntu` → `ubuntu`, `kde-logo` → `kde`).
2. `curl -sL <url> -o <path-tujuan>.svg` — simpan **dengan nama file yang
   SAMA seperti sekarang** (`node-icon.svg` / kalau mau tetap PNG, convert
   pakai `rsvg-convert` atau `inkscape --export-type=png`), supaya
   `loader.js` & `Animation.jsx` tidak perlu diubah sama sekali.
3. Kalau butuh recolor jadi monokrom (biar konsisten kayak style guide
   linux-vs-unix/desktop-environment) → edit fill SVG jadi
   `currentColor`/abu-abu pakai `sed`, atau convert manual.
4. Simpan versi asli SVG juga di folder yang sama (`*-original.svg`) buat
   arsip/lisensi, tambahkan file `LICENSE-LOGOS.md` singkat yang
   nyantumin sumber tiap logo (Simple Icons = CC0, cukup 1 baris credit).

### Contoh script (dijalankan via Desktop Commander terminal)

```bash
cd /home/adb/Projects/Personal/mcp-servers-animation/mcp-servers-animation/src/content/container-docker/icons

curl -sL https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/nodedotjs.svg -o node-icon.svg
curl -sL https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/python.svg    -o python-icon.svg
curl -sL https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/redis.svg    -o redis-icon.svg

# convert ke PNG transparan kalau Animation.jsx masih expect PNG
for f in node-icon python-icon redis-icon; do
  rsvg-convert -w 512 -h 512 "$f.svg" -o "$f.png"
done
```

(Perlu cek dulu apakah `rsvg-convert`/`inkscape` sudah terpasang di mesin
kamu — kalau belum, saya bisa install dulu lewat terminal yang sama.)

# Plan Tambahan: Icon Baru untuk Momen yang Masih Text-Only

**Konteks**: Selain logo yang kurang akurat, ada masalah kedua —
banyak momen penting di `container-docker` cuma ditampilkan sebagai
teks polos (Badge/TextCard) tanpa icon pendamping, padahal momen itu
justru yang paling penting buat pemahaman audiens (insight, trade-off,
payoff). Berikut audit lengkap + rencana penambahan icon.

## 1. Cek Elemen "Wajah" di Act 1 (yang ditanyakan)

Posisi persis: di bawah Meter RAM/CPU, di atas hook question
"Kenapa jalanin app kecil aja laptop udah teriak?" — itu adalah
`FaceCharacter`, komponen **SVG digambar manual di `Animation.jsx`**
(baris ~434), BUKAN emoji Unicode dan BUKAN file icon:

```jsx
const FaceCharacter = ({ x, y, happy }) => (
  <g transform={`translate(${x},${y})`}>
    <circle r={26} fill={COLORS.PANEL} stroke={COLORS.BORDER} strokeWidth={2} />
    <circle cx={-9} cy={-6} r={3} fill={COLORS.TEXT} />   {/* mata kiri */}
    <circle cx={9} cy={-6} r={3} fill={COLORS.TEXT} />    {/* mata kanan */}
    {happy
      ? <path d="M -10 8 Q 0 18 10 8" ... />               {/* senyum */}
      : <path d="M -10 12 Q 0 4 10 12" ... />}              {/* sedih */}
  </g>
)
```

Ini konsisten dengan pola lama di `tailscale` SEBELUM mereka bikin
`face-happy.png` / `face-surprised.png` sebagai file icon asli (lihat
`tailscale/icons/icons.json`). Container-docker belum di-upgrade ke pola
itu — masih inline SVG.

**Opsi**: (a) biarkan inline SVG (sudah cukup jelas & ringan, bukan
prioritas), atau (b) generate jadi `face-happy-icon.png` /
`face-sad-icon.png` biar konsisten style-nya sama icon lain & gampang
di-tweak desainnya tanpa sentuh kode. Rekomendasi: **opsional, prioritas
rendah** — bukan sumber masalah utama.

`DiagramBox`), supaya icon baru bisa langsung dipasang tanpa ubah
struktur ulang tiap pemanggilan:

```jsx
const Badge = ({ x, y, text, color = COLORS.DOCKER, w = 280, icon = null }) => (
  ...
  {icon && <image href={getIcon(icon)} x={16} y={h/2 - 10} width={20} height={20} />}
  ...
)
```

Lalu tinggal tambah `icon="question-icon"` dkk di masing-masing
pemanggilan yang relevan (13 titik di tabel §2).
