## 🗣️ User Wants

### Rangkuman (dirapikan dari prompt asli)

User suka pola di **Act 5**: ada urutan flowchart yang jelas (node → path
menyala berurutan mengikuti amplop terbang). Untuk revisi ini, prinsip itu
mau diperluas jadi aturan umum:

1. **Minimalkan text box terpisah** (TextCard/Badge/SpeechBubble yang berdiri
   sendiri di layar) — **lebih banyak icon**.
2. Kalau memang butuh teks, taruh di salah satu dari dua tempat:
   - **Di bawah icon** yang bersangkutan, atau
   - **Di tengah-tengah flowchart**, tepat di titik "benang" (path/garis)
     sedang berjalan.
3. Tujuannya: **penonton tidak perlu melirik ke bawah** (ke caption bar
   `say()` yang sekarang posisinya terpisah dari aksi utama) untuk baca teks.
4. Idealnya teks "otomatis kebaca" karena mata penonton memang lagi di situ:
   - saat mengikuti benang/path yang lagi jalan, teks nempel di situ → auto
     kebaca, atau
   - saat icon baru muncul, teks nempel di bawah icon itu → auto kebaca.

### Prompt asli (verbatim, untuk histori)

> "kita buat revisi 4, saya suka di act 5, ada urutan flow chart gitu,
> skrang say apingin minim text box, lebih bnyak icon, nanti textnya taruh
> di bawah icon atau di tengah2 flowchart pas benangnya jalan, jadi audiens
> ga perlu ngelirik ke bawah buat baca, pas ngikutin benang jalan auto baca,
> atau pas icon muncul nanti kan auto baca"
