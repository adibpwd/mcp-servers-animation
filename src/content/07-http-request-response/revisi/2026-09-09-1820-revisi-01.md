## 4. Default/Placeholder Icon — Supaya Preview Gak Rusak Sebelum Icon Asli Ada

**Masalah:** `icons.json` + wiring ke `Animation.jsx` bakal mereferensi 7
icon id di atas, tapi PNG asli baru ada setelah kamu generate manual
lewat ChatGPT (langkah manual, gak bisa saya lakukan). Kalau langsung
wire tanpa fallback, preview bakal broken image / kosong sebelum kamu
generate.

**Solusi:** siapkan **1 file placeholder** (`default-icon.png`) —
bukan hasil AI-generate, bukan download dari internet, tapi digambar
sendiri secara lokal (shape netral simple, misal lingkaran abu-abu +
tanda "?"). `icons/loader.js` di-set supaya `getIcon(id)` fallback ke
placeholder ini kalau file asli icon itu belum ada:

```js
// src/content/http-request-response/icons/loader.js
import defaultIcon from './default-icon.png'
import envelopeClosedIcon from './envelope-closed.png' // akan gagal import kalau belum ada file-nya!
// ...

export const ICONS = {
  'envelope-closed': envelopeClosedIcon,
  // ...
}

export function getIcon(id) {
  return ICONS[id] || defaultIcon
}
```

**Catatan teknis penting:** pola `import` ES module di atas **gagal build**
kalau file PNG belum ada sama sekali (bukan runtime fallback, tapi
compile-time error). Jadi urutan eksekusi yang aman:

1. Buat `default-icon.png` dulu (1 file, lokal, hari ini juga bisa).
2. `loader.js` di-generate HANYA meng-import icon yang PNG-nya sudah
   benar-benar ada di folder — untuk 7 icon yang masih nunggu ChatGPT,
   `ICONS[id]` sengaja belum dikasih entry (biar gak `import` file yang
   belum ada), jadi `getIcon(id)` otomatis jatuh ke `defaultIcon` lewat
   fallback `|| defaultIcon`, BUKAN karena file-nya diimport terus gagal.
3. Begitu kamu generate 1 icon asli lewat ChatGPT extension → PNG masuk
   ke folder → baru saya tambah 1 baris `import` + 1 entry `ICONS` buat
   icon itu. Icon lain yang belum digenerate tetap fallback ke default,
   gak perlu nunggu ke-7-nya sekaligus.

Jadi ya, sesuai permintaan kamu: **boleh semua icon keliatan sama
(placeholder) dulu di preview**, nanti diganti satu-satu begitu hasil
ChatGPT masuk — gak perlu nunggu lengkap 7-7-nya buat mulai preview.

berakhir x=540, masih di dalam lebar pill 560px). Sekarang teks badge
(kiri) dan dot navigator (kanan) satu baris/sejajar di dalam pill yang
sama, gak ada lagi yang nongol duluan di atas.

- [x] Hapus wrapper `<g transform="translate(50, -18)">`, ganti jadi
      `<g transform="translate(440, 20)">` langsung di dalam grup pill

      transform grup)
- [x] Cek teks badge terpanjang (`"ACT 3 — NYARI ALAMAT & KETUK PINTU"`,
