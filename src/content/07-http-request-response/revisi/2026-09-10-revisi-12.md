## 🔍 Diagnosis — State Sekarang

### Struktur path yang ada sekarang

`DualColorPath` punya dua jalur terpisah, masing-masing 3 titik:

```
FORWARD_POINTS: Browser(410,260) → DNS(610,620) → Server(410,900)
RETURN_POINTS:  Server(410,900) → via kiri(210,620) → Browser(410,260)
```

Masalahnya: **`FORWARD_POINTS` dimulai langsung dari Browser ke DNS**
— tidak ada segmen "Browser → Amplop" sama sekali. Jadi saat Act 1
amplop "berangkat" dari browser, garis forward baru **mulai menyala
dari titik DNS** (di Act 2 saat `forwardPathPct` digerakkan), bukan
dari browser.

Timeline yang mengontrol `forwardPathPct`:
- Act 1: tidak ada tween `forwardPathPct` sama sekali — state-nya tetap
  0 selama seluruh Act 1 (amplop terbang tanpa "benang" apapun)
- Act 2 mulai: tween `fwd1` dari 0 → 0.5 (segmen Browser→DNS menyala)
- Act 2 beat 4: tween `fwd2` dari 0.5 → 1.0 (segmen DNS→Server menyala)

Jadi gap yang user rasakan: di Act 1 amplop terbang dan tersegel, tapi
**tidak ada benang sama sekali yang menghubungkan browser ke amplop**.
Benang baru nongol di Act 2 — dan langsung "mulai dari browser" (bukan
dari posisi amplop yang sekarang — karena path titiknya memang dari
browser, bukan dari amplop). Terasa disconnect / berantakan.

### Root cause

Dua hal terpisah yang bikin "berantakan":
1. **Act 1: `forwardPathPct` tidak pernah digerakkan** → tidak ada
   benang selama amplop fly dari browser ke bawah
2. **Titik awal `FORWARD_POINTS[0]` = browser (410,260)** → benang
   "langsung ada dari browser" bukan "tumbuh dari browser seiring
   amplop jalan"

---

## 💡 Proposal Fix

### Prinsip

Benang forward harus **tumbuh secara real-time dari browser mengikuti
amplop**, dari Act 1 sampai Act 2, terus-menerus tanpa putus. User
tidak boleh pernah melihat benang "muncul tiba-tiba" atau "loncat".

### A — Tambah titik waypoint "amplop Act 1" ke FORWARD_POINTS

Sekarang forward path punya 2 segmen (Browser→DNS, DNS→Server). Perlu
ditambah **1 segmen awal**: Browser → titik "surat berangkat" (amplop
tersegel Act 1, kira-kira y=700 area tengah layar, sesuai posisi
`envelopeAnchor` dan `reqEnvelope` setelah morph).

```
FORWARD_POINTS baru (4 titik, 3 segmen):
  [0] Browser    (410, 260)
  [1] Amplop Act1 (410, 700)   ← titik waypoint baru
  [2] DNS        (610, 620)
  [3] Server     (410, 900)
```

Dengan 3 segmen, `forwardPathPct` sekarang range 0–1 mewakili
perjalanan: 0–0.33 (Browser→Amplop), 0.33–0.67 (Amplop→DNS),
0.67–1.0 (DNS→Server).

### B — Tween `forwardPathPct` mulai dari Act 1 (seiring amplop terbang)

Di Act 1, saat amplop turun dari browser (t+3.3, `popIn envelopeAnchor`),
mulai tween `forwardPathPct` dari 0 → 0.33 (segmen Browser→Amplop
menyala seiring amplop turun). Duration ~0.9s ikut durasi fly amplop.

```
t+3.3 → fwd0: { v: 0 } to { v: 0.33, duration: 0.9, ease: 'power2.in' }
         (bareng terbangnya envelopeAnchor dari browser ke y=700)
```

Catatan: `forwardPathPct` perlu di-reset ke 0 di awal Act 1 (sudah ada
di `setPhaseIdx(0)` block — perlu ditambah `setForwardPathPct(0)` kalau
belum ada, cek dulu).

### C — Sesuaikan tween Act 2 (fwd1 & fwd2) ke range baru

Sekarang fwd1 jalan 0→0.5 (karena dulu 2 segmen). Dengan 3 segmen:

| Tween | Dulu | Baru |
|---|---|---|
| `fwd1` (Browser→DNS, Act 2 beat 1) | 0 → 0.5 | 0.33 → 0.67 |
| `fwd2` (DNS→Server, Act 2 beat 4) | 0.5 → 1.0 | 0.67 → 1.0 |

Start value `fwd1` dari 0 → 0.33 karena akhir Act 1 sudah set
`forwardPathPct` ke 0.33 (segmen pertama sudah menyala).

### D — `FORWARD_PATH_LABELS` disesuaikan (3 label, 1 per segmen)

Sekarang `FORWARD_PATH_LABELS = ['cari alamat', 'connect']` (2 label
untuk 2 segmen). Dengan 3 segmen perlu 3 label:

```js
const FORWARD_PATH_LABELS = ['surat berangkat', 'cari alamat', 'connect']
```

Label pertama `'surat berangkat'` muncul di tengah segmen
Browser→Amplop (midpoint ~y=480), warna `COLORS.CLIENT`.

### E — PathPin ikut otomatis (tidak perlu perubahan)

`PathPin` sudah pakai `FORWARD_POINTS` dan `forwardPathPct` secara
generik — begitu titik ditambah dan pct disesuaikan, pin otomatis
bergerak di posisi yang benar. Tidak perlu perubahan.
