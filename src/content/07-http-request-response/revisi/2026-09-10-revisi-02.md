## Perubahan di Animation.jsx — Fitur Baru

### A. State Baru

| State | Tipe | Kegunaan |
|---|---|---|
| `starBursts` | `[]` | Array burst partikel bintang flying out radial |
| `shockWaves` | `[]` | Array ring shockwave expanding-fade (stamp slam) |
| `flashOpacity` | `0` | Screen flash sementara (stamp impact) |
| `thinkProg` | `0` | Progress 0-1 loop untuk animasi bounce thinking dots |
| `envelopeTrail` | `[]` | Last 8 posisi amplop untuk comet trail |
| `pathProgress` | `0` | 0-3: segmen path journey yang sudah menyala |
| `browserPulse` | `0` | 0-1 intensitas pulse ring di browser (Act 1) |
| `confettiPieces` | `[]` | Confetti celebration Act 6 |

### B. Ref Baru

| Ref | Kegunaan |
|---|---|
| `burstIdRef` | counter unik ID per star burst |
| `waveIdRef` | counter unik ID per shockwave |
| `confettiIdRef` | counter unik ID per confetti |
| `envelopeTrailRef` | ref versi dari `envelopeTrail` untuk capture di onUpdate tanpa stale closure |

### C. Helper Baru

| Helper | Params | Efek |
|---|---|---|
| `triggerBurst` | tl, time, cx, cy, colors[] | 12 bintang terbang keluar radial dari titik, fade 0.8s |
| `triggerShockWave` | tl, time, cx, cy, color | 3 ring expanding, time-offset 0-0.15-0.3, fade 0.7s |
| `triggerFlash` | tl, time, color, opacity | White/colored flash rect seluruh canvas, fade 0.3s |
| `triggerConfetti` | tl, time, cx, cy | 20 confetti pieces, warna-warni, gravity down |

### D. Komponen Baru

| Komponen | Kegunaan |
|---|---|
| `StarField` | 30 bintang background statik, opacity rendah |
| `StarBurstsLayer` | Render semua active `starBursts` |
| `ShockWavesLayer` | Render semua active `shockWaves` |
| `PathVisualization` | Dashed line client→DNS→server→client, menyala per `pathProgress` |
| `PulseRing` | Expanding ring berulang (browser loading) |
| `ConfettiLayer` | Render confetti celebration Act 6 |
| `ThinkingDotsAnim` | 3 dots bounce naik-turun bergelombang (bukan statis) |
