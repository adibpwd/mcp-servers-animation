Browser nggak langsung ambil halaman yang kamu ketik — ada proses kirim-surat dulu. 📨

Ketik URL → browser nulis "surat" (request) → cari alamat aslinya lewat DNS → ketuk pintu server → server baca & proses → kirim balasan (response) dengan stempel status code.

Status code itu stempel di amplop balasan: 200 hijau (OK), 404 merah (Not Found), 500 merah tua (Server Error). Bukan cuma angka — tapi penentu nasib halaman yang kamu lihat.

Jadi bukan "ambil", tapi kirim surat dan terima balasan. 📬
