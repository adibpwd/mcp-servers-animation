Setiap kali kamu buka profil di aplikasi, browser cuma ngirim 1 dari 5 "kata sakti" ke server: GET, POST, PUT, PATCH, DELETE. 📮

Tapi tunggu... abis browser BIKIN data baru (POST), kenapa harus nanya ULANG (GET) buat nampilin kartunya? Ternyata server nggak otomatis "ngasih tau balik" isi lengkapnya — dia cuma bilang berhasil dibuat, browser sendiri yang harus balik ambil datanya.

GET = minta data, POST = bikin baru, PUT = ganti semua sekaligus, PATCH = ganti sebagian doang, DELETE = hapus. 5 kata ini yang bikin semua aplikasi web bisa "ngobrol" sama server-nya.
