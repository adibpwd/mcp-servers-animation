## 2. Temuan Kunci

1. **11 motion signifikan TOTAL SILENT** (baris merah 🔴 di atas) —
   termasuk 3 entrance elemen utama di awal Act 1 (browser/server/eaves),
   1 reveal privasi bocor, 2 payoff reject (impostor X, fake-key
   dipantulkan), 1 mirror-tween yang pincang (ingredient B), dan **tween
   terpanjang di Act 4 (kapsul 1.9s) tanpa suara sama sekali** — motion
   paling fokus visual di seluruh Act 4 justru paling sepi.
2. **1 dead config di `SFX_MAP`**: `POP2` (`ui/pop-2`) didefinisikan di
   `data.js` tapi **tidak pernah dipanggil** di `Animation.jsx` —
   melanggar checklist §3 `08-audio-sfx-generation.md` ("entry yang
   didefinisikan tapi tidak pernah dipanggil adalah sinyal config sudah
   basi"). Rencana ini sekalian mem-fix dengan mem-wire `POP2` ke
   ingredient B (§1 #22) — pas secara semantik (mirror asimetris dari
   ingredient A yang pakai `POP`).
3. **Blocker teknis**: helper `popOut()` di `Animation.jsx` (baris
   ±126-132) sama sekali tidak punya parameter `sfx`/`sfxCategory`/
   `sfxName` — beda dengan `popIn()` yang sudah lengkap. Ini yang bikin
   §1 #25 (kunci palsu dipantulkan) tidak bisa dikasih suara tanpa
   ubah helper dulu.
4. **Observasi sekunder (bukan blocker, di luar scope revisi ini)**:
   `DING` dipakai 5× di seluruh topic (browserHttps, serverVerified,
   keyBadge, serverOpen, closingStamps) — cukup repetitif untuk 5 beat
   naratif yang berbeda konteks. Didokumentasikan sebagai kandidat
   revisi-02 kalau user mau diversifikasi lebih lanjut; **tidak
   dikerjakan di revisi-01 ini** supaya scope tetap fokus ke "isi yang
   sepi", bukan "ganti yang sudah ada".

## 5. Perubahan Kode yang Diperlukan (selain `SFX_MAP`)

`popOut()` (Animation.jsx, dekat definisi `popIn`) perlu diupgrade agar
sejajar dengan `popIn()` — terima opsi `sfx`/`sfxCategory`/`sfxName`:

```js
// SEKARANG — tidak ada opsi SFX sama sekali
const popOut = (tl, time, id, opts = {}) => {
  const { duration = 0.3, ease = 'power1.in' } = opts
  const o = { v: 1 }
  tl.to(o, { v: 0, duration, ease, onUpdate: () => setPop(...) }, time)
}

// RENCANA — sejajar dengan popIn(), default sfx:false (biar topic lain
// yang sudah pakai popOut() tanpa opsi tidak berubah perilakunya)
const popOut = (tl, time, id, opts = {}) => {
  const { duration = 0.3, ease = 'power1.in', sfx = false,
    sfxName = SFX_MAP.POP.name, sfxCategory = 'ui', volumeMult = 1 } = opts
  const o = { v: 1 }
  tl.to(o, {
    v: 0, duration, ease,
    onStart: () => { if (sfx) sfxLoader.play(sfxCategory, sfxName, { volume: volume * volumeMult, speed }) },
    onUpdate: () => setPop(prev => ({ ...prev, [id]: { ...(prev[id] || {}), scale: o.v, opacity: o.v } })),
  }, time)
}
```

Default `sfx: false` dipilih supaya perubahan ini **tidak mengubah
perilaku topic lain** yang mungkin juga pakai pola `popOut()` serupa
(scope revisi ini cuma 23-https-tls) — motion #25 akan eksplisit set
`sfx: true, sfxCategory: 'ui', sfxName: SFX_MAP.BOUNCE.name`.
