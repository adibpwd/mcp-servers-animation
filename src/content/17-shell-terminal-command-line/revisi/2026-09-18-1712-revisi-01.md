| Item | Nilai |
|---|---|
| Status | PLAN ONLY — belum ada perubahan kode, aset, atau registry |
| Masalah | Implementasi Act 1 saat ini memakai `LAYER_CARDS` dan narration bubble yang menyorot empat istilah secara bergantian. Bentuknya dominan kotak + teks, sehingga audiens membaca definisi sebelum melihat hubungan terminal, command line, PTY, dan shell. |
| Tujuan | Dalam beberapa detik pertama audiens melihat satu command diketik, dibawa ke shell, dijalankan sistem, dan hasilnya kembali ke terminal. Nama komponen hanya menjadi label pendek pada benda yang sedang bekerja. |

## Keputusan Cakupan

Revisi ini memperbaiki **Act 1** tanpa memperluas scope ke parsing detail, streams, environment, atau scripting. Enam Act yang ada tetap dapat dipakai, tetapi Act 1 berubah dari “empat kartu istilah” menjadi **overview motion**. Act 2 dan seterusnya kemudian mengurai bagian yang sudah dilihat audiens.

Tujuan video tetap:

> Terminal menampilkan interaksi; command line menerima ketikan; shell membaca dan mengatur command; sistem menjalankan tugas.

## State Contract Act 1 yang Direvisi

| State | Yang terlihat | Yang belum boleh terlihat | Pemicu | Hasil |
|---|---|---|---|---|
| Terminal idle | Satu jendela terminal, prompt kosong | Penjelasan panjang, output, atau node detail | Terminal dibuka | Command line menjadi fokus |
| Command diketik | Karakter `pwd` tumbuh di baris prompt | Output path atau shell result | Enter ditekan | Command capsule lahir dari input line |
| Shell memproses | Capsule bergerak melalui PTY ke shell hub | Output path | Capsule tiba di shell | Shell hub menyala dan meneruskan tugas |
| Sistem selesai | Capsule mencapai system task node | Output sebelum tugas selesai | System apply | Hasil path kembali ke terminal |
| Overview stabil | Terminal, PTY cable, shell hub, system node tersambung | Materi parsing/streams detail | Output tiba | Audiens melihat empat peran sebagai satu alur |

## Storyboard Pengganti untuk Act 1

| Beat | Before → intent → travel → apply → after | Copy in-video maksimum |
|---|---|---|
| 1. Layar menerima input | Terminal window kosong → prompt muncul → cursor berkedip di satu command line → command `pwd` diketik → line menerima teks. | Tidak perlu kalimat; cukup label kecil `COMMAND LINE` yang menunjuk baris aktif. |
| 2. Bukan terminal yang menjalankan | Command sudah terlihat di line → Enter ditekan → capsule `pwd` keluar dari input line → bergerak melalui kabel PTY → masuk shell hub → shell menyala. | `SHELL` pada hub. |
| 3. Tugas dijalankan | Shell hub aktif → task pulse bergerak ke system node → task tiba → system node menyala → output capsule lahir. | `SYSTEM` pada node. |
| 4. Hasil kembali | Output capsule kembali melalui shell/PTY → ditulis sebagai `/home/adib` di terminal → seluruh alur menahan state → tiga highlight pendek menunjuk terminal, command line, dan shell. | `Terminal menampilkan. Shell mengatur.` |

**Aturan keras:**

- Hapus narration bubble panjang dan urutan `Terminal Emulator — ...`, `Command Line — ...`, `Shell — ...`, `PTY — ...` dari Act 1.
- Jangan membuat empat card sebagai pengganti. Objek harus memperoleh arti dari gerakannya.
- Command dan output tidak boleh tampil bersamaan sejak awal; output baru lahir setelah system apply.
- PTY tidak perlu menjadi card besar. Ia cukup kabel virtual berdenyut, dengan label kecil `PTY` saat capsule melewatinya.
- Shell tidak boleh hanya menyala sebagai text box. Beri bentuk hub/decoder dengan animasi internal ring berputar atau tiga token masuk → satu task keluar.
- Act 2 harus mulai dari overview stabil ini: terminal, PTY cable, shell hub, dan system node tetap mounted; hanya detailnya yang ditambah. Tidak ada reset canvas.

## Timeline, Audio, dan Reset

- Ganti timeline `act1Row`/highlight empat kartu dengan state: `typedCommand`, `commandPacket`, `shellActive`, `systemActive`, dan `outputText`.
