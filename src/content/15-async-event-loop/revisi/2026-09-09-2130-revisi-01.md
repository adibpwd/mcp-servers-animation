## 1. Masalah #1 — Intro Tidak Ada Efek Typing

### Kondisi sekarang (`15-async-event-loop`)

Intro cuma `popIn` biasa lalu morph — TIDAK ada teks yang diketik
karakter-per-karakter:

```js
// Animation.jsx ~baris 118-124
popIn(tl, t + 0.05, 'introBlock', { fromY: 16, duration: 0.35, ... })
tl.add(() => sfxLoader[SFX_METHOD.transitions](SFX_MAP.WHOOSH_LOW.name, ...), t + 0.5)
const mo = { p: 0 }
tl.to(mo, { p: 1, duration: 0.6, ease: 'power3.inOut', onUpdate: () => setMorphP(mo.p) }, t + 0.5)
tl.add(() => setShowIntro(false), t + 1.1)
```

State yang dipakai cuma `showIntro` + `morphP` — tidak ada `typed` /
`cursorVisible` sama sekali. Total durasi intro juga cuma `1.2s`
(`PHASES[0].duration`), kependekan buat nampung efek ketik yang wajar.

### Acuan (`14-http-request-response`) — pola "hacker typing → morph"

Sudah ada pola baku dipakai di `http-request-response`, `tailscale`,
`container-docker`. Elemen kuncinya:

- State tambahan: `typed: { title: '', subtitle: '' }` dan
  `cursorVisible` (blink cursor `|` di ujung teks yang lagi diketik).
- Helper `typeLine(tl, startTime, lineKey, fullText, opts)` — nambah
  karakter satu-satu ke `typed[lineKey]`, delay antar-karakter RANDOM
  tapi **deterministik** (`seededRandom01(i * 12.9898 + lineSeed)`,
  bukan `Math.random()` — wajib karena timeline di-build ulang tiap
  proses Chrome saat export paralel).
- SFX `TYPING` (`sfx/typing.wav`) dipanggil per-karakter (atau
  di-throttle beberapa karakter sekali, biar gak berisik) — key ini
  SUDAH ada di `SFX_MAP` topic ini (`TYPING: { category: 'sfx', name:
  'typing' }`) tapi belum pernah benar-benar dipanggil di manapun
  (dead config, lihat checklist plan §10 poin Audio).
- Setelah teks selesai diketik → baru morph ke header kecil (pola
  `morphP` yang sudah ada TETAP dipakai, cuma dipicu setelah typing
  selesai, bukan langsung dari awal).

**Catatan:** `INTRO_CATEGORY` (dipakai `http-request-response` sebagai
label kecil di atas title, misal `"NETWORKING"`) belum ada di
`async-event-loop/data.js` — kalau mau intro benar-benar identik gaya
(bukan cuma efek ketik-nya), perlu ditambah juga, misal
`INTRO_CATEGORY = 'PROGRAMMING CONCEPTS'`. **Perlu dikonfirmasi user
dulu** — apakah cuma efek typing yang mau disamakan, atau seluruh
struktur intro (badge kategori + typing + morph) full sama persis
kayak `http-request-response`.
