Semua file Linux punya satu titik awal: slash.

Di home seorang developer biasanya ada Projects, Downloads, Documents, Videos, juga folder tersembunyi seperti .config dan .ssh. Di dalam Projects, repository aplikasi punya src, tests, package.json, dan README.

Etc menyimpan konfigurasi layanan seperti nginx, ssh, docker, dan systemd. Program yang dipanggil terminal lazim tersedia di usr atau opt. Saat aplikasi berjalan, log dan cache bertambah di var; hasil build sementara bisa singgah di tmp.

Begitu paham pohonnya, path seperti slash home slash adib slash Projects slash inventory-api slash src slash server.js tidak lagi terasa asing.

Simpan video ini sebelum mulai belajar terminal.
