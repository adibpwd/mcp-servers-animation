## 🎯 Core Idea

Revisi 2 sudah kurangi teks dan tambah efek partikel. Tapi tiap Act masih
terasa "scene terpisah." Revisi 3 mengubah **paradigma narasinya**: seluruh
animasi adalah **satu perjalanan yang divisualisasikan sebagai flowchart hidup**,
bukan kumpulan scene.

Prinsip utama:
- **Flowchart IS the story** — bukan background dekorasi, tapi tulang punggung narasi
- **Icon grammar replaces text** — penonton *baca* icon, bukan *baca* kalimat
- **Connected transitions** — elemen kunci tiap act mengalir ke act berikutnya
- **Dual-color path** — request (pergi) = biru, response (balik) = hijau

## 🗺️ Flowchart Spine (Persistent Sepanjang Animasi)

Dari Act 1, ada jalur dashed yang selalu kelihatan (dim), menyambungkan 5 node:

```
[🌐 BROWSER] ──────> [📖 DNS] ──────> [🏢 SERVER]
      ↑                                      │
      └──────────────────────────────────────┘
         (return path, dim sampai Act 5)
```

- **Node** = icon PNG yang sudah ada (browser-frame, dns-magnify, server-building)
- **Path forward** = warna CLIENT biru (#38BDF8), menyala Act 1→3
- **Path return** = warna SUCCESS hijau (#34D399), menyala Act 5→6
- **Node glow** = scale pulse + drop-shadow filter saat node sedang aktif
- **Seluruh path flash** = Act 6 payoff — semua segment nyala sejenak lalu dim

## 🔧 State Baru di Animation.jsx

| State | Tipe | Kegunaan |
|---|---|---|
| `activeNode` | `null \| 'browser' \| 'dns' \| 'server'` | Node mana yang sedang glow |
| `forwardPathPct` | `0–1` | Seberapa jauh path biru sudah menyala (Browser→DNS→Server) |
| `returnPathPct` | `0–1` | Seberapa jauh path hijau sudah menyala (Server→Browser) |
| `pathFlash` | `boolean` | True saat Act 6 full-path flash |
| `thoughtBubbleIcon` | `null \| string` | Icon key yang tampil di dalam ThoughtBubble |
| `browserFilled` | `boolean` | False = kosong, True = browser terisi halaman |

## 📐 Layout FlowchartSpine

Posisi node di canvas (VW=820, VH=1340):

```
Browser  (cx=120, cy=300)  — kiri atas
DNS      (cx=700, cy=300)  — kanan atas
Server   (cx=700, cy=700)  — kanan bawah
                    ↑
        return path naik dari server ke browser (cx=120, cy=700 → cx=120, cy=300)
```

Path forward:  Browser(120,300) → DNS(700,300) → Server(700,700)
Path return:   Server(700,700) → titik balik(120,700) → Browser(120,300)

Node size: 64×64px icon PNG, centered di koordinat node.
Path: `<polyline>` SVG strokeDasharray animated, stroke-width 3, opacity dim 0.2 saat idle.
